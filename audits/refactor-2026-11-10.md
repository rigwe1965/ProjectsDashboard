## Things to know

- **Not run:** `npm run test:e2e`, and the Postgres store (no `TEST_DATABASE_URL`). Neither was touched, but neither was exercised either.
- **Not run:** a real customer link against a live demo app with Docker. The unit tests drive the proxy and private-copy paths with fake upstreams.
- **Line endings:** some files in this repository use Windows line endings (CRLF) and some use plain (LF); `redeem.mjs` is one of the CRLF files. Edits kept each file's own endings, which is why the diffs are small. A search-and-replace that assumes plain newlines will silently fail on those files.
- **`'admin-app-' + action`:** the console still builds `admin-app-start`, `admin-app-stop` and `admin-app-restart` from text, so they are not in `EVENTS`.
